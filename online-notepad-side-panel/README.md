# Online Notepad Side Panel

A private, offline-ready browser notepad for text, SQL, Markdown, JSON and source code.

## Features

- Multiple notes with autosave, search, pinning, trash and recovery
- White editor with font, size, color, rich-text and spellcheck controls
- Syntax highlighting and line numbers for SQL and common code formats
- Board and draggable, resizable sticky-note canvas views
- Find and replace, word and character count, print/PDF and editing tools
- Individual downloads, workspace backups and ZIP export
- Text and code imports only; images and binary files are rejected
- Offline app cache, responsive layout and keyboard shortcuts

## Privacy

There is no server database, account, analytics or note upload. Notes are stored in localStorage for the current browser and site address. Download regular backups before clearing browser data.
